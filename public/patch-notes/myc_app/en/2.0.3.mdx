# 2.0.3 Release Notes

## 1. My Wine (Duplication)

- Fixed an issue where the app didn’t navigate to the wine list after
  duplication.

- Resolved a problem preventing tasting notes for duplicated wines in the
  “Tasted + Recorded” state.

- Duplicated wines now default to “In Storage,” with the storage and purchase
  dates set to the duplication date.

## 2. My Wine (Edit)

- Fixed an issue where vintage info didn’t update during edits.
