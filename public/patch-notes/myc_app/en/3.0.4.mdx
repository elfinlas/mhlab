# Upcoming Features Roadmap

The upcoming updates will focus on further refining day-to-day usability.

<br />
Below is a preliminary roadmap for future development. Please note that these
items are subject to change based on QA testing and development priorities.
<br />

These changes will be integrated into versions 3.0.5 or 3.1.0. <br />The
immediate next release will be v3.0.5, followed by v3.1.0 which will introduce
web authentication and cloud integration features.

## Home Dashboard

- Home Screen UI Overhaul (v3.1.0)

## Wine Management

- Web-powered Auto-Fill for wine registration data (v3.1.0)
- Expanded Grape Varietals Database (v3.1.0)
- Redesigned Wine Summary Analytics (v3.0.5)

## Tasting Notes

- Added Filter criteria for "Repurchase Intent" (v3.0.5)
- Redesigned Tasting Summary Dashboard (v3.0.5)

## Wine Cellar

- Enhanced UI for in-cellar inventory lists (v3.0.5)
- Restructured Cellar Summary Metrics (-)

## Miscellaneous

- Multi-language localization support (Japanese, French) (v3.0.5)
- Added Wine Knowledge & Educational Reference screen (-)
- Launch and cloud synchronization for the MaWaCel Web Platform (v3.1.0 or
  v3.1.1)

<br />

We are committed to bringing you more advanced features. Wishing you a wonderful
and delightful wine journey!
