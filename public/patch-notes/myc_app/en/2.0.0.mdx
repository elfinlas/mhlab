# 2.0.0 Release Notes

## 1. New UI

- The interface has been updated from the old, cumbersome design to a new,
  streamlined one.

## 2. Wine Filters

- Added filter options for wine status, type, and storage location.

## 3. Wine Summary

- View summaries of your wine collection and the history of recorded wines.

## 4. Wine Cellar Features Improved

- Added shelf functionality to view wines stored on specific shelves.
