# 새로워진 부분의 요약

| 구분       | 설명                                    |
| ---------- | --------------------------------------- |
| `홈`       | 종합적인 정보 표시 기능 개선            |
| `와인`     | 와인 검색 및 상세, 요약 정보 표시 기능  |
| `시음노트` | 상세 타입과 요약 정보 추가 및 기능 개선 |
| `와인셀러` | 셀러 관리 및 보관 위치 표시 기능 개선   |
| `설정`     | 앱 설정 기능 개선                       |

- 최신 항목 위주 표시: 홈 화면이 너무 길어지지 않도록 최근 등록한 와인은 4개,

- 이미지 비율 개선: 와인 썸네일이 찌그러져 보이던 현상을 수정하여, 어떤 비율의

  표시됩니다.
- 시음 노트에 작성일자가 표시됩니다.

  문제를 해결했습니다.
