# 3.0.2 버전 패치 안내

[주요 안내 사항]

- 2.X 버전에서 3.X 버전 마이그레이션을 하면서 일부 시음 노트에 저장된 사진
  데이터가 삭제되는 이슈가 생겼습니다.
- 이 부분에 대해서 사과드립니다.
- 불편하시더라도 이번 버전에서 다시 등록해서 사용해주시면 감사하겠습니다.

## 1. 사진 문제

- 일부 시음 노트 및 와인 등록에 사용되었던 사진의 저장소가 잘못 지정되는 문제를
  수정

## 2. 시음 노트 수정

- 시음 노트 수정 시 와인 선택 부분의 화면이 생략됩니다.

## 3. 시음 노트 열람

- 평점이 소수점인 경우 별 점수에 반영이 안되던 문제 수정
- 평점과 함께 표기 방법으로 변경

## 4. 셀러 열람

- 이미지 표시를 개선하였습니다.

불편을 드려 진심으로 죄송합니다. 이용해주셔서 감사합니다.
