# 2.0.3 버전 패치 안내

## 1. 나의 와인 (복제)

- 복제 후 와인 리스트로 넘어가지 않는 문제

- 마심 + 기록 상태의 와인을 복제하였을 때 복제된 와인의 시음 노트 작성이
  불가능한 문제

- 와인 복제 시 상태는 보관 상태로 변경되게끔 수정

- 와인 보관 날짜는 복제한 날짜로 변경되며, 구입 날짜 값이 있는 경우 복제한
  날짜로 변경

- 와인 복제 시 사진이 사라지는 문제 수정

## 2. 나의 와인 (수정)

- 와인 수정 시 빈티지 정보가 변경되지 않는 문제 수정

이용해주셔서 감사합니다.
