# 2.0.2 버전 패치 안내

## 1. 나의 와인

- 검색의 보관 장소의 필터 값이 보관 중인 상태만 적용되는 문제 수정
- 열람 시 기타 속성의 값이 개발 테스트 용 문구가 뜨는 문제 수정
- 정보 수정 시 열람 화면 데이터가 바로 적용되지 않던 문제 수정
- 와인 상태 변경 시 보관 장소가 이상한 값으로 변경되는 문제 수정

## 2. 나의 셀러

- 보관 중인 와인만 노출되어야 하는데 다른 상태의 와인이 노출되는 문제 수정
- 보관 중인 와인이 없는 경우 보관된 와인과 선반 정보가 노출되지 않도록 수정
