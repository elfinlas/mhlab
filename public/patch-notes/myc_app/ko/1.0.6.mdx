# 1.0.6 버전 패치 안내

## 1. 나의 와인 리스트에서 보유 와인 검색 기능 추가

- 보유 와인 리스트 화면에서 검색 기능 추가
- 와인 이름 기준으로 검색하여 결과를 제공

## 2. 나의 와인 리스트의 필터링 기능 추가

- 보유 와인에서 보관, 마심, 기록 등 상태별로 필터링 기능이 추가

## 3. 설정 기능 추가

- 앱 리뷰 평가 하기 기능 추가
- 만든이의 일부 기능 변경
- 패치노트 확인 기능 추가

## 4. 기타

- 보관일의 시간 표시의 디테일 추가
- 시음노트에 와인 이름이 짤려서 표시되는 문제 수정
- 나의 와인 열람 시 보관일이 있는 경우 보관 기간 표시 추가
- 셀러의 보유 와인에서 이름이 짤려서 표시되는 문제 수정
- 와인 상태 변경 시 아이콘 일부 변경
- 셀러 내의 보유 와인에서 보유 중인 상태 와인만 표시
- 메인 화면의 보유 와인 카운팅이 보관중 상태의 와인만 집계
