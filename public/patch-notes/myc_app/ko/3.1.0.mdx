# 참고 및 다음 패치 예정 내역

- 최근 마와셀 웹 개발 및 연동 작업을 진행하고 있습니다.
- 또한 와인 가격 정보은 웹 버전에서 오픈하였습니다.
  [참고](https://mywinecellar.info/wine_price)
- 다음 버전에서 앱으로 해당 기능은 들어올 예정입니다.
- 패치가 예정보다 늦어진 점에 대하여 양해 부탁드리며, 향후 버전에서 적용될
  내역들 중 큰 기능에 대해 간략하게 소개드립니다.
- 차후 버전은 4.X 대에서 시작되는 기능이며, 순차적으로 적용될 예정입니다.

<br />

## 적용될 내역

### 회원 기능

- 회원 기능이 추가될 예정이며, 이메일 로그인 방식으로 진행될 예정입니다.
  - SNS 계정 로그인 기능은 제외될 예정입니다.
- 사용자 그룹 기능이 추가될 예정입니다.
  - 해당 기능은 4.X 이후 적용될 예정입니다.
  - 사용자 그룹을 추가하여 시음 노트 및 와인 관리를 공유할 수 있게 됩니다.

<br />

### 대대적인 UI 변경

- 전체적으로 UI가 대폭 개편될 예정입니다.
- 메인 화면부터 시작해서 새로운 화면으로 개발을 기획 준비 중입니다.

<br />

### 와인

- 웹 연동 버전부터는 와인 정보 웹에서 받아오는 기능이 추가될 예정입니다.
- 초창기 와인 정보 부족으로 인해 기능이 부족할 수 있습니다만, 지속적으로
  데이터를 쌓을 예정입니다.
- 포도 품종에 대한 기능이 추가될 예정이며, 이와 관련된 기능이 추가될 예정입니다.
- 요약 기능을 좀 더 개선하여 한눈에 보기 편하게 개선될 예정입니다.

<br />

### 시음 노트

- 시음 노트가 웹과 연동되면서 공유하기 기능이 추가됩니다.
- 검색 필터가 더 세밀하게 적용될 예정입니다.
- 시음 노트를 기반으로 사용자 취향을 분석할 수 있는 기능이 추가될 예정입니다.

<br />

### 와인 셀러

- 웹과 연동되면서 셀러 내역을 웹에서도 확인할 수 있게 됩니다.
- 시각적인 효과를 개선하여 더 보기 편하게 개선될 예정입니다.

<br />

### 기타

- 다국어 출시 (일본어, 프랑스어)
- 와인 지식 컨텐츠 추가 예정 (-)
- 포도 품종 및 아로마에 대한 컨텐츠 추가 예정

<br />

앞으로 더 많은 기능을 제공할 예정이며, 즐거운 와인 생활 하시길 바랍니다.
