# 다음 패치 예정 내역

다음 패치에는 몇 가지 사용성을 개선하는 작업을 진행할 예정입니다. <br/>아래는
패치 예정 리스트 이며, 내역은 확정된 내역은 아니며, 변경될 수 있습니다. <br/>

적용될 버전은 3.0.5 또는 3.1.0 버전에 적용될 수 있습니다.<br /> 다음 버전은
3.0.5 이며, 웹 로그인 기능 등을 추가한 3.1.0 버전이 출시될 예정입니다.

## 홈 화면

- 홈 화면 UI 개선 (3.1.0)

## 와인

- 와인 등록 시 정보 웹에서 받아오는 기능 (3.1.0)
- 포도 품종 데이터 추가 (3.1.0)
- 요약 화면 재구성 (3.0.5)

## 시음 노트

- 재구매 여부 필터 기능 추가 (3.0.5)
- 요약 화면 재구성 (3.0.5)

## 와인 셀러

- 셀러의 보유 와인 화면 UI 개선 (3.0.5)
- 셀러 요약 화면 재구성 (-)

## 기타

- 다국어 출시 (일본어, 프랑스어) (3.0.5)
- 와인 지식 관련 화면 추가 (-)
- 마와셀 웹 버전 출시 및 연동 (3.1.0 or 3.1.1)

<br />

앞으로 더 많은 기능을 제공할 예정이며, 즐거운 와인 생활 하시길 바랍니다.
