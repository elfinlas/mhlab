# 2.0.0 버전 패치 안내

## 1. 새로운 UI

- 기존의 복잡하고 투박한 UI에서 새로운 UI로 변경되었습니다.

## 2. 와인 필터

- 와인 상태, 타입과 더불어 저장 위치에 대한 필터 기능을 추가하였습니다.

## 3. 와인 요약

- 보유한 와인의 요약, 지금까지 기록되었던 와인의 히스토리를 볼 수 있습니다.

## 4. 와인 샐러 기능 개선

- 와인 선반 기능이 추가되어, 선반 별로 보관중인 와인을 확인할 수 있습니다.

이용해주셔서 감사합니다.
