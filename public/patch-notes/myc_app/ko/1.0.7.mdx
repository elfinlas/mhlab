# 1.0.7 버전 패치 안내

## 1. 보유와인에서 와인 타입에 따른 보기 필터 추가

1. 보유와인에서 와인 타입에 따른 보기 필터 추가

- 보유와인 리스트 화면에서 상단 우측에 메뉴에 와인타입필터 메뉴가
  추가되었습니다.
- 이를 통해 보유 와인의 레드, 화이트 등의 타입에 따라 와인 검색을 도울 수
  있습니다.

## 2. 보유와인 리스트의 필터 조건 표시

- 리스트 화면 상단에 현재 적용된 필터 조건을 확인할 수 있습니다.

## 3. 시음노트 작성 시 보유 와인 검색 기능

- 기존에 보유 와인이 너무 많을 경우 대상 선정에 어려움이 있었습니다.
- 시음노트 작성 시 보유 와인을 선택하면 와인을 검색할 수 있습니다.

## 4. 시음노트 검색 기능

- 시음노트 리스트에서 검색 기능이 추가되었습니다.
- 대상 와인명을 입력하면 검색 와인에 대한 시음노트가 검색됩니다.

## 5. 기타

- 추후 웹 버전과 연동되는 부분 준비
- 와인 정보 구조 변경(웹 정보 가져오기 준비)
- 기타 일부 로직 수정

이용해주셔서 감사합니다.
